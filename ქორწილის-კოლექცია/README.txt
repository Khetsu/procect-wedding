ამბავი · ქორწილის კოლექცია
==========================
დახვეწილი, რეალისტური 3D მოსაწვევები (ნათება, ჩრდილები, ბროლი/ოქრო/აბრეშუმი, ბუნდოვანი ფონის შუქები).
index.html იხსნება პირდაპირ (ორჯერ დაჭერით) — სერვერი არ სჭირდება.

  champagne — 🥂 შამპანურის კოშკი · მელოდია: gala    (script ბოთლის ეტიკეტზეც იწერება)
  chapel    — 🕯 სანთლების ტაძარი · adagio
  rings     — 💍 ბეჭდები აბრეშუმზე · celesta
  veil      — 🤍 ფატა · ballad
  cake      — 🎂 საქორწილო ტორტი · serenade        (ტორტზე ინიციალები a/b სახელებიდან)

ახალი კლიენტისთვის:
  1) დააკოპირე დიზაინის საქაღალდე ახალი სახელით (მაგ. rings → ana-luka)
  2) შეცვალე მხოლოდ config.js (სახელები, თარიღი, პროგრამა, ადგილი, phone — WhatsApp ნომერი)
  3) node _engine\build.cjs
  4) powershell -File ატვირთვა-vercel.ps1 -folder ana-luka -name ana-luka
