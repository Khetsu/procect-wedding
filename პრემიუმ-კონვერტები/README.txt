ამბავი · პრემიუმ კონვერტები
============================

ხუთი მოსაწვევი, თითოს თავისი 3D კონვერტი და თავისი გახსნა. სტუმარი ბმულს ხსნის, ეკრანზე კონვერტი ხვდება,
შეეხება და კონვერტი მის თვალწინ იხსნება მუსიკით. შიგნიდან ბარათი ამოდის და იქცევა მოსაწვევის „ბარათების ნაკრებად“.

დიზაინები (თითო საქაღალდე = ერთი მზა მოსაწვევი, index.html ორმაგი დაწკაპუნებითაც იხსნება):
  wax-seal  ცვილის ბეჭედი: ბეჭედი ტყდება, სარქველი იხსნება, ბარათი მოფრინავს        ქორწილი     მელოდია valse (ვალსი)
  ribbon    აბრეშუმის ლენტი: ფიონი იხსნება, ლენტი ჩამოსრიალდება, ორი კარი იღება   ქორწილი     მელოდია emerald (ფორტეპიანო)
  bloom     ყვავილის კონვერტი: ოთხი ფურცელი ყვავილივით იშლება                     ნიშნობა     მელოდია blossom (მუსიკალური ყუთი)
  stars     ვარსკვლავების წერილი: ოქროს ძაფი ღილებიდან იხსნება                     ნათლობა     მელოდია lullaby (იავნანა)
  noir      ოქროს დანა: ქაღალდის დანა ნაპერწკლებით ჭრის კონვერტს                  იუბილე      მელოდია noir (ჯაზი)

ბარათები გახსნის შემდეგ: მთავარი (სახელები, თარიღი) → ჩვენი ამბავი → უკუთვლა და კალენდარში დამატება →
დღის პროგრამა → ადგილი და რუკა → დრეს-კოდი → დადასტურება (WhatsApp) → „გელოდებით“.

სტუმრის სახელი კონვერტზე
------------------------
ბმულს ბოლოში მიუწერეთ ?to=სახელი, მაგ.  https://mariam-giorgi.vercel.app/?to=ნინო
კონვერტზე დაიწერება „ძვირფასო ნინო,“. ასე თითოეულ სტუმარს თავისი ბმული გაუგზავნეთ.

ახალი კლიენტისთვის
------------------
1. დააკოპირეთ სასურველი დიზაინის საქაღალდე ახალი სახელით (მაგ. wax-seal → mariam-giorgi).
2. გახსენით config.js და შეცვალეთ:
     a, b          სახელები (ნათლობაზე და იუბილეზე მხოლოდ a; იუბილეზე big = "50")
     latin, mono   ლათინური სახელები და მონოგრამა (მაგ. "M&G")
     date, time    "2027-07-10", "18:00"
     kicker, city, story, sign
     program       დრო, სათაური, ადგილი, icon (church · glass · dinner · music · ring · cake · camera · star · heart)
     venue         name, addr, map (რას ეძებს Google Maps)
     palette, dressNote, rsvpBy
     phone         WhatsApp ნომერი დადასტურებისთვის, მაგ. "995598000000"
     music         valse | emerald | blossom | lullaby | noir
     theme         ფერები (ნებაყოფლობითი)
3. ბრძანება (პრემიუმ-კონვერტები საქაღალდიდან):   node _core/build.cjs mariam-giorgi
   (ყველას გადასაწყობად: node _core/build.cjs)
4. ატვირთვა:   powershell -File ატვირთვა-vercel.ps1 -folder mariam-giorgi -name mariam-giorgi
   ბმული: https://mariam-giorgi.vercel.app. ეს ბმული გაუგზავნეთ კლიენტს Facebook-ზე.

ხრიკი პრეზენტაციისთვის: ?auto (კონვერტი თავისით იხსნება 2 წამში)
