ამბავი · პრემიუმ დიზაინები
===========================

სრულიად ახალი ძრავი: ძველიდან არაფერია გამოყენებული.
ფონი არის ცოცხალი WebGL შეიდერი, რომელიც ტელეფონში რეალურ დროში იხატება.
მუსიკა ახალი ძრავით (aria.js) იქმნება, ბრაუზერშივე.

დიზაინები (თითო საქაღალდე = ერთი მზა მოსაწვევი, index.html ორმაგი დაწკაპუნებითაც იხსნება):
  liquid-gold  თხევადი ოქრო: ოქროს წვეთები ერწყმის და ბეჭდად იქცევა        მელოდია velvet
  aurora       ჩრდილოეთის ციალი: ცა ინთება მთებსა და გაყინულ ტბაზე          მელოდია borealis
  galaxy       გალაქტიკა: აფეთქება, ორი ვარსკვლავი ერწყმის და გალაქტიკა იბადება   მელოდია stardust
  fireworks    ფეიერვერკი: რაკეტა გულად სკდება ღამის ქალაქზე              მელოდია celebration
  silk         აბრეშუმი: სინათლის ზოლი აბრეშუმს აჩენს                       მელოდია satin
  vitrage      ვიტრაჟი: ტაძრის ვიტრაჟი რგოლ-რგოლ ინთება                    მელოდია cathedral

გვერდის წყობა: გახსნა (დააჭირეთ და გააჩერეთ) → სახელები → ამბავი → უკუთვლა →
პროგრამა (გვერდზე გადასაწევი ბარათები) → ადგილი და რუკა → დრეს-კოდი → დადასტურება → დასასრული.

ახალი კლიენტისთვის
------------------
1. დააკოპირეთ სასურველი დიზაინის საქაღალდე ახალი სახელით (მაგ. liquid-gold → ana-luka).
2. გახსენით config.js და შეცვალეთ:
     a, b          სახელები (კორპორატიულზე მხოლოდ a)
     introScript   ლათინური ხელნაწერი სახელები გახსნის ეკრანზე
     date, time    "2027-06-26", "18:00"
     city, story, sign, program, venue (map = რას ეძებს Google Maps)
     palette, dressNote, rsvpBy
     phone         WhatsApp ნომერი დადასტურებისთვის, მაგ. "995598000000"
     music         velvet | borealis | stardust | celebration | satin | cathedral
     theme / scene ფერები (ნებაყოფლობითი)
3. ბრძანება (პრემიუმ-დიზაინები საქაღალდიდან):   node _core/build.cjs ana-luka
   (ყველას გადასაწყობად: node _core/build.cjs)
4. ატვირთვა:   powershell -File ატვირთვა-vercel.ps1 -folder ana-luka -name ana-luka
   ბმული: https://ana-luka.vercel.app. ეს ბმული გაუგზავნეთ კლიენტს Facebook-ზე.

ხრიკები ბმულში:  ?auto (თავისით იხსნება, პრეზენტაციისთვის)  ·  ?q=.5 (სუსტ ტელეფონზე უფრო მსუბუქი ხატვა)

  _core\build.cjs                    აწყობს index.html-ს (შეიდერი შიგ ჩაშენებულია, file:// მუშაობს)
